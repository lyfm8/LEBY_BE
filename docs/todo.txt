2. QUY CHUẨN KIẾN TRÚC & TIÊU CHUẨN KỸ THUẬT BẮT BUỘC CHO BE
--------------------------------------------------------------------------------

1. Chuẩn Phản Hồi API Toàn Cục (Unified ApiResponse Envelope):
   Mọi endpoint BẮT BUỘC trả về định dạng chuẩn:
   {
       "success": boolean,
       "message": string | null,
       "data": T | null
   }
   - Thành công: ResponseEntity.ok(ApiResponse.success(data, "Thông báo nếu cần"))
   - Lỗi: GlobalExceptionHandler bắt và đóng gói ApiResponse.error(errorCode, message)

2. Cơ Chế Xác Thực & Phân Quyền (JWT qua HTTP-Only Cookie):
   - KHÔNG lưu token trong LocalStorage của trình duyệt (tránh tấn công XSS).
   - Backend set Cookie: Set-Cookie: access_token=...; HttpOnly; Secure; SameSite=Lax; Path=/
   - Mọi request từ FE tự động gửi kèm cookie (apiClient.withCredentials = true).
   - Tự động kiểm tra TokenVersion trong User Entity để vô hiệu hóa ngay khi logout hoặc đổi pass.

3. Quản Lý Transaction & Toàn Vẹn Dữ Liệu:
   - Tất cả các nghiệp vụ chấm thi, sinh lộ trình, cập nhật năng lực phải bọc trong:
     @Transactional(rollbackFor = Exception.class)
   - Tuyệt đối không để xảy ra trường hợp: Đã lưu kết quả thi nhưng lỗi ở bước cập nhật UserAbility
     dẫn đến mất đồng bộ dữ liệu.

4. Quy Tắc Ánh Xạ CSDL (Zero Waste - Không Thừa, Không Thiếu):
   - Toàn bộ 27 JPA Entities trong dự án đều phải tham gia vào chu trình dữ liệu.
   - Bảng abilities, user_abilities, ability_aim_plans, learning_paths đóng vai trò hạt nhân trung tâm.
